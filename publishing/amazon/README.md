# Words Have Weather - Amazon release pack

This folder contains six pre-publication Kindle packages. Each title folder has:

- a fixed-layout EPUB 3 manuscript with live text, image descriptions, a navigation document and one XHTML file per page;
- a 1600 x 2560 px portrait JPEG cover;
- a metadata record with description, age range, learning focus, suggested discovery terms and content-disclosure notes.

The site edition also includes a touch-friendly reader and a landscape education PDF. The Amazon EPUB is the same story but is packaged separately for Kindle quality review.

## Release decision

Use standard KDP distribution, not KDP Select, while the education editions remain available from the Words Have Weather site. KDP Select requires Kindle eBook exclusivity during its enrolment period, which would conflict with the free off-Amazon edition.

## Required pre-publication review

1. Complete human editorial, illustration continuity, accessibility, safeguarding and rights review for all twelve pages.
2. Open each EPUB in the latest Kindle Previewer and check tablet, phone and e-reader views. Fixed-layout books do not reflow, so test every page and orientation.
3. Confirm the cover, title, subtitle, series data, age range, categories, description, pricing and territories in the KDP title setup.
4. Disclose AI-generated text and images in KDP. Amazon treats actual text or images produced by an AI-based tool as AI-generated even after substantial edits.
5. Upload the EPUB manuscript and portrait JPEG cover. Review the online preview again before publishing.
6. Keep the books out of KDP Select unless the free site editions are removed and the exclusivity decision is made deliberately.

## Current official references

- [KDP supported eBook manuscript formats](https://kdp.amazon.com/en_US/help/topic/G200634390/) - EPUB is supported and Amazon recommends checking it in Kindle Previewer.
- [Fixed-layout books with positioned text](https://kdp.amazon.com/en_US/help/topic/GFFHCXVPHRZW8SJ5) - required metadata, one HTML file per page, layout and magnification guidance.
- [Kindle Previewer](https://kdp.amazon.com/en_US/help/topic/G202131170) - device preview and fixed-layout quality checks.
- [KDP eBook cover specifications](https://kdp.amazon.com/en_US/help/topic/G200645690) - ideal cover size is 1600 x 2560 px and JPEG or TIFF.
- [KDP content and AI disclosure guidelines](https://kdp.amazon.com/en_US/help/topic/G200672390) - AI-generated text and images must be disclosed.
- [KDP Select](https://kdp.amazon.com/en_US/help/topic/G200798990) - optional 90-day Kindle eBook programme with digital exclusivity requirements.
- [Apple Books fixed-layout guidance](https://authors.apple.com/support/3975-designing-great-book-layouts-interiors) - fixed-layout EPUB is recommended for children's books and illustration-heavy titles.

These files are production candidates, not proof that Amazon or Apple has approved the books. Account identity, tax and payment details, pricing, rights, territories and the final publish action remain with the publisher.
